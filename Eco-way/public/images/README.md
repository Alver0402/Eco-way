# Imágenes para EcoWay

Esta carpeta contiene las imágenes utilizadas en la aplicación EcoWay en lugar de emojis.

## Imágenes requeridas:

1. **profile.png** - Icono para "Mi Perfil" (80x80px recomendado)
2. **guides.png** - Icono para "Guías de Reciclaje" (80x80px recomendado)
3. **activities.png** - Icono para "Registro de Actividades" (80x80px recomendado)
4. **points.png** - Icono para "Puntos de Reciclaje" (80x80px recomendado)
5. **streak.png** - Icono para la sección de racha (80x80px recomendado, circular)

## Recomendaciones:

- Formato: PNG con fondo transparente
- Tamaño: 60x60 píxeles para consistencia
- Estilo: Verde ecológico, minimalista
- Tema: Relacionado con reciclaje y medio ambiente

## Ubicación:

Coloca estas imágenes en: `public/images/`

Si no tienes las imágenes, puedes usar generadores de iconos como:
- Flaticon
- Icons8
- Material Design Icons
